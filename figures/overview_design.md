# MiUrchin overview

The watercolor header is AI-assisted artwork based on the MiCucumber visual format. Animal illustrations are schematic. Badge lengths are current representative reference spans for SD, MD, L and XL: 188, 228, 343 and 440 bp.

Scientific coordinates are rendered separately as `binding_positions.svg` from the selected oligo intervals by `positions.py`. All rows use one linear coordinate scale; arrows point toward the amplified interval. Exact coordinates, primer/reference sequences and mismatch counts are in `results/current/binding_positions.csv`. The map shows homologous binding intervals, not guaranteed amplification of the reference accession by every pair.
