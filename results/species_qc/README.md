# MiUrchin 物种参考面板

每个 WoRMS 可核实物种保留一条代表序列；参考序列从原始数据恢复并重新比对。未定种或无法核实的记录不计入物种覆盖。
输入 1401 条记录，保留 165 个物种。

| 长度 | 可评价物种 | 不可评价物种 |
|---|---:|---:|
| S | 55 | 110 |
| M | 158 | 7 |
| L | 159 | 6 |
| XL | 55 | 110 |

可评价区域需在正反两个结合窗口均覆盖并有足够明确碱基；缺失区域不作为漏检。序列代表的选择依据为窗口完整性、模糊碱基和位点覆盖，不依据引物匹配。
