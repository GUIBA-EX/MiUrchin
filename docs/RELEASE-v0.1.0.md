# MiUrchin v0.1.0 — Computational candidates / 计算候选版

Four mitochondrial 16S length series for Echinoidea: XS 188–193 bp, S 221–250 bp, M 316–346 bp, L 440–458 bp in the respective eligible region panels. Includes distinct Separate/Pool schemes, full primer sequences and allowed pairings, bilingual documentation, region figures, frozen reference data and revalidation scripts.

海胆线粒体16S四长度系列：各自区域面板中的预测产物为XS 188–193 bp、S 221–250 bp、M 316–346 bp、L 440–458 bp。包含不同的独立PCR/混合方案、完整引物与配对、中英双语文档、区域图、冻结参考数据和复现脚本。

The common comparison uses 49 labels/80 haplotypes; own-region panels contain 55 or 165 labels and cannot be compared as identical taxon sets. All eight schemes meet the stated computational risk and structural gates. This is not a wet-lab validated universal assay. Review exact-match coverage, missing taxa and wider mismatch background risks before experimental evaluation.

共同面板为49标签/80单倍型；各区域为55或165标签，不能当作相同分类群比较。8个方案均通过指定计算风险和结构阈值，但不属于经湿实验验证的通用引物。实验前请结合完全匹配率、缺失分类群及放宽错配条件下的背景风险审阅。
