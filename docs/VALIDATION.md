# Validation / 验证

Current primer sequences, fixed coordinates, degeneracy, independent target/background checks and README links are checked with `python3 scripts/check_species_release.py`. Raw hit sets and comparison tables are available in `results/species_refine/`. Historical analysis remains in its original results directories.
