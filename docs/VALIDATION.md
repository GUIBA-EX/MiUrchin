# Validation / 验证

The current release contains eight compact portfolios, twelve paired entries and twenty-four FASTA entries. All 1,920 per-reference comparisons between aligned-window predictions and an independent full-sequence scan agree. Background unions satisfy WC≤3 ≤5 and GT≤2 ≤5; thermodynamic checks pass for all selected pairs.
