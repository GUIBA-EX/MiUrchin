# Shared coordinates / 共同坐标

Each length retains one exact forward/reverse coordinate tuple on NC_001453.1 for ordinary, A, B and D. The D optimization changes IUPAC sequences within these boundaries; it does not move binding windows. S/M/L/XL reference spans are 188/228/343/440 bp, including primers.

每长度普通与 D共用同一组F/R起止坐标。此次D优化仅调整坐标内的IUPAC碱基集合，不移动位点；跨度为188/228/343/440 bp（含引物）。

Current D scores and gates: [D optimization](D_OPTIMIZATION.md). Current candidates and their validation are described in the main README.
