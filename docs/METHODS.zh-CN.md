# 方法

参考坐标使用 NC_001453.1 去除空位后的线粒体 16S rRNA，采用 1-based 坐标。XS 与 XSD 的正向位置为 183–204、反向位置为 344–363，含引物的参考跨度为 181 bp。每个 S–XL 区域的正反向引物起止坐标固定；含引物的参考跨度依次为 188、228、343、440 bp，实际产物长度随类群变化。

XS 筛选借鉴 [MiFish](https://doi.org/10.1098/rsos.150088) 比较目标类群保守侧翼和标记区域变异的思路。MiFish 针对鱼类 12S，MiUrchin 针对海胆 16S；普通 XS 搜索固定 XSD 的起止坐标，约束末端 3 nt，并筛查非目标和引物结构。本 XS 扩增区的物种分辨率尚未评估。搜索范围与覆盖、完全匹配的取舍见[候选比较](../results/current_primers/XS/ordinary_screening.md)。

目标库包含 1,401 条记录。经分类与序列质量审核，每个物种保留一条代表，共 165 个物种；XS、S、M、L、XL 分别有 55、55、158、159、55 个物种可评价。非目标库包含 6,045 条记录。主覆盖率和完全匹配率对可评价物种等权，各目的结果单列；缺失结合区域不计为漏检。

预测覆盖要求每条引物最多 2 个错配且末端 3 nt 与 IUPAC 碱基兼容；完全匹配要求两条引物均无错配。S–XL 的目标双引物扫描要求产物总长 150–500 bp、引物间内部长度至少 50 bp；XS 与 XSD 的要求分别为 70–500 bp 和至少 20 bp。非目标扫描允许内部长度 0–1,000 bp。WC3 与 GT2 为不限制末端的宽松筛查，严格 WC 与 GT 保留末端约束。命中数为参考记录数。

候选引物每条最多 8 个具体变体，简并位点仅在 3′ 半段。末端检查排除末端三连和超过 4 bp 的同聚物，要求末端 3 nt 含 GC。Primer3 使用 50 mM 单价盐、1.5 mM Mg²⁺、0.6 mM dNTP，并评估每变体 50 nM 与每方向总量 200 nM 两种情景；结构 Tm 须低于 55°C，正反向双链 Tm 中点差不超过 5°C。

C++ 与 Python 独立扫描使用同一参考数据，属于算法复核，不等于独立生物样本验证。[分析脚本](../scripts/species_screening/README.md)作为过程记录保留，实际表现仍需实验验证。
