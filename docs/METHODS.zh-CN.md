# 当前方法与证据边界

主方案为原始 32 对不分分类群的普通／D 引物。补充清单包含 76 对分支／分类群限定候选，对应 32 组原方案；以下设计方法主要描述补充候选。65对优先验证、11对条件备选。全部按独立F/R组合分别PCR，不是可直接混用的引物池。普通引物保持非简并；某些D方案在保守分支内也可以成为非简并。

首先保障设计组内双端3′最后三位匹配，再分配内部简并或移动窗口。首轮最多64个变体／端，移动窗口轮最多16个；后者长度18–27nt，一般端点移动±20nt，COI S扩展至±50nt。每组至少3条记录，属级分组不等于重新验证了单系性。

所有覆盖率只指该行设计记录。目标双端各≤2错配且末端三位严格WC相容，产物60–650bp；背景两引物间距0–1000bp。严格WC／GT与宽松WC≤3／GT≤2四项计数均不得高于原引物，不要求原本非零的计数变为零。没有验证分支特异性，也没有把其他海胆全部作为该分支的非目标。

展开全部简并变体，检查发夹、自二聚体、池内变体相互二聚体及F/R异二聚体。50nM／变体与200nM／方向两情景；单价盐50mM、Mg1.5mM、dNTP0.6mM；结构Tm<55°C、引物Tm45–75°C、中点Tm差≤5°C。结构温度余量至少5°C列为优先，其余为条件备选。未加入接头，不能据此直接确定实验退火温度。

全部76对已用冻结原始序列重新扫描并核对原版对照；独立 Python 算法复核目标配对及完整归档背景库的严格 WC／GT 匹配，两种浓度下结构参数重新计算。移动窗口候选另核对预定位置和产物长度。COI S等混合方案存在交叉非目标命中，因此分别PCR。

设计和筛选使用相同面板，没有独立留出或湿实验验证。历史物种覆盖、共同面板、属级留出和条码分辨率结果归入legacy/v1.2，不能描述新引物。后续已对全部条目计算已取得条码之间的内部序列唯一性，但这不是全库物种分辨率或种内条码间隙评价；缺失、分类未定及未采样物种不能计为已覆盖。
