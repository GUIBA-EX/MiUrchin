# 12S and COI candidate assays

The NCBI search and alias retrieval yielded 9,988 distinct accession records. The downloads directory preserves compressed GenBank batches and query snapshots. The sequence audit records feature locations, selection and exclusions. The independent panels contain 69 named species for 12S (208 eligible sequences) and 314 for COI (9,392 eligible sequences). Each gene directory includes all eligible sequences, one representative per species, a reference alignment, background representatives and per-assay results.

Reference spans define XS (150–185 bp), S (186–210 bp), M (211–250 bp), L (251–350 bp) and XL (351–470 bp). Candidate D oligonucleotides have at most eight variants and ambiguity in the 3′ half. Ordinary pairs were selected among concrete variants at the same endpoints. Screening prioritized exact matches for 12S and window availability for COI. A compatible paired target product spans 100–500 bp with an internal insert of at least 50 bp, at most two mismatches per primer and compatible terminal three bases. Background assays allow internal distances of 0–1,000 bp. Both strict Watson–Crick pairing and pairing allowing guanine–thymine matches screens admit up to ten non-target species, both relaxed screens up to fifty. The frozen-window comparison uses a separate denominator for each locus.

From this directory, run `python3 scripts/final_check.py` with Biopython and primer3-py installed. It independently checks both strands against the archived paired scans and recomputes target, background, coordinate, degeneracy and thermal metrics. The 16S analysis is documented in the repository README.
