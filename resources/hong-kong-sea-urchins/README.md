# Hong Kong sea-urchin records: interactive map

[在线交互地图 / Interactive map](https://guiba-ex.github.io/MiUrchin/) · [地图 HTML 文件 / Map HTML](index.html) · [返回项目主页 / Project README](../../README.md)

这份独立交互地图整理香港海胆记录，包含 20 个地点或站位、物种筛选、地点详情和文献来源。它是区域背景资源，**并非 MiUrchin 引物验证或覆盖率评估**。

## 如何使用

可直接打开在线地图；如需离线查看，在 GitHub 打开上方 HTML 文件后，使用文件页面的下载功能将其保存到本地，再用浏览器打开；GitHub 的源码页面不会运行交互地图。底图和交互脚本嵌在文件内，地图本身无需联网；打开外部文献和 Google Maps 链接需要联网。

## 数据与限制

- 点位混合原始文献站位、馆藏坐标和地名代表位置，定位精度不同；部分地名及标本鉴定仍待核实。
- 底图来自 Yiu & Mah (2024) 图 1，按图中刻度近似配准；因此不适合精确测距或空间分析。原地图内保留逐点来源、备注和文献链接。
- 没有标记不表示物种缺失；地图还单独显示香港范围外的历史船站，不能将其作为香港本地发生记录。
- 原始文件 `香港海胆分布地图.html` 以未修改内容保存为 `index.html`，SHA-256 为 `779f4961b504db2e8ff8c805a05021cd6fc8ce2eaae803960c74539b88fe6e53`。

## English

Open the interactive map online, or download [index.html](index.html) and open it in a browser; the GitHub file view displays source, not the running page. The map embeds its basemap and scripts; external references and Google Maps require internet access. The 20 plotted locations combine sampled stations, museum records and approximate representative localities, with varying uncertainty. The Yiu & Mah (2024) Figure 1 basemap is approximately georeferenced; the map is unsuitable for precise spatial analysis. Some identifications and place-name matches remain unresolved. Offshore historical stations are distinguished from Hong Kong records. This map is contextual and is not a primer validation dataset.
