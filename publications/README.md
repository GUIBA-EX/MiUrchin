# MiUrchin manuscripts

The revised manuscript presents the original **32 non-partitioned ordinary/D pairs first**, followed by 76 supplementary branch- or taxon-limited entries. It is a computational study, not peer reviewed; author declarations remain to be completed before journal submission.

The revision draws on the design/evaluation frameworks of Bae (2025) and Marquina, Andersson and Ronquist (2019). This revision adds archived-reference coverage, terminal compatibility, expanded-variant structure, recovered-insert identity and published COI comparator analyses in Supplementary Data S9. Primer sequences are unchanged. These analyses do not provide independent external or experimental validation. S7/S8 retain archival wording and relative paths; resolve these against the source commit recorded in the manifest.

The [earlier branch-focused manuscript](MiUrchin_preprint.md) and its [PDF](MiUrchin_preprint.pdf) remain available. `scripts/build_paper.py` rebuilds that earlier manuscript only; it does not regenerate the revised Word/PDF package. `scripts/build_revised_manuscript.py` rebuilds the editable revised documents; its package contains document dependencies. The [v1.2 manuscript](../legacy/v1.2/publications/MiUrchin_preprint.md) preserves the primary-panel analysis. Existing ResearchGate drafts are separate historical user files.
